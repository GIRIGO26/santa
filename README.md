# Schneeball-Gruß

Ein Weihnachtsgruß als kleine Geschichte im Browser: Die Schachtel wirft einen Schneeball auf den Bildschirm,
dann folgt eine Schneeballschlacht gegen das Team und am Ende der Gruß.

Dieses Repository enthält nur die fertige Seite (`index.html` und `app.js`), ausgeliefert über GitHub Pages.

## Name des Empfängers

Der Name steht am Ende der Adresse und erscheint auf dem Namensschild:

- `.../#Anna-Becker` wird zu „Anna Becker“
- `.../#Anna--Lena-Becker` wird zu „Anna-Lena Becker“ (zwei Bindestriche sind ein echter Bindestrich)

## Kamera-Modus

Oben rechts auf „AR“ tippen und Bewegungssensor und Kamera erlauben. Das Handy dorthin richten, wo das
Geschenk stehen soll.
